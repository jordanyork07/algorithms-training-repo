# Interview Study Plan

This plan is designed for a focused algorithms interview prep cycle. Priority is to build pattern recognition and speed before breadth.

## Phase 1: Core pattern mastery (highest priority)

Start here before trying harder problems.

### P0 patterns
- Arrays and strings
- Hash maps and frequency counting
- Two pointers
- Sliding window
- Prefix sums
- Binary search
- BFS and DFS
- Greedy algorithms

### Recommended order
1. Arrays and strings
2. Hash maps
3. Two pointers and sliding window
4. Prefix sums
5. Binary search
6. BFS and DFS
7. Greedy
8. Dynamic programming
9. Backtracking
10. Trees and graphs
11. Linked lists and stacks/queues

## Phase 2: Depth and consistency

Once the core patterns are comfortable, revisit the remaining categories.

### P1 patterns
- Stacks and queues
- Trees and graphs
- Recursion and backtracking
- Dynamic programming
- Heaps and top-k
- Linked lists

### P2 patterns
- Harder DP variants
- Rare union-find patterns
- Niche edge-case problems
- Advanced graph problems beyond the standard interview bar

## Weekly study rhythm

### If you have 3 days
- Day 1: arrays, hash maps, two pointers, sliding window
- Day 2: binary search, BFS/DFS, greedy
- Day 3: dynamic programming, trees/graphs, timed mock interview

### If you have 1 week
- Days 1-2: P0 patterns
- Days 3-4: P1 patterns
- Day 5: timed mock interview and re-solve weak problems
- Day 6: fix weak spots and review patterns aloud
- Day 7: light revision and final mock run

## How to use each problem
For every problem:
1. Restate the problem in your own words.
2. Clarify constraints and edge cases.
3. Attempt a brute-force solution first.
4. Identify the bottleneck.
5. Derive the improved approach.
6. State the complexity before coding.
7. Write the solution.
8. Check examples and small edge cases.
9. Re-solve from a blank file after a break.

## Interview strategy
- Spend no more than 10-15 minutes on a stuck problem before switching to a simpler one.
- Practice explaining the trade-off between brute force and optimized solutions.
- Keep a short list of trigger phrases for each pattern.
- Run at least 2 timed mock interviews before the actual interview.
