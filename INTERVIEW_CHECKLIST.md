# Interview Checklist

## Before the interview
- [ ] Review the P0 patterns once more
- [ ] Re-solve the hardest 3 problems from memory
- [ ] Practice explaining complexity aloud
- [ ] Check the meeting setup and environment
- [ ] Prepare one blank file and one test harness file
- [ ] Make sure the screen share and audio are working

## During the interview
- [ ] Restate the problem
- [ ] Clarify the input and output
- [ ] Ask about edge cases and constraints
- [ ] Provide a brute-force approach
- [ ] Explain the optimization
- [ ] State time and space complexity before coding
- [ ] Write clean, readable code
- [ ] Test the example and one edge case

## After the interview
- [ ] Review what you missed
- [ ] Record the patterns you struggled with
- [ ] Revisit those problems the next day
