# Stacks and Queues

This topic focuses on ordered processing problems where the latest item or the earliest item matters. Typical patterns include matching brackets, monotonic stacks, and simulating state as values are added and removed.

## Problems in this folder
1. valid_parentheses
   - Given a string containing parentheses, determine whether the sequence is balanced.
   - Typical interview cues: matching pairs, nesting, filtering invalid input.
2. daily_temperatures
   - For each day, return how many days you must wait before a warmer temperature appears.
   - Typical interview cues: monotonic stack, next greater element.

## What to practice
- Stack push/pop operations
- Reasoning about invariants while scanning left-to-right
- Distinguishing the stack from the queue when the problem implies order constraints
