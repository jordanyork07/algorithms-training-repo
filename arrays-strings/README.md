# Arrays Strings

Practice problems for this topic live in this directory.

## Problems in this folder
1. contains_duplicate
   - Check whether the list contains a duplicate value.
2. group_anagrams
   - Group strings that are anagrams of each other.
3. valid_anagram
   - Determine whether two strings are valid anagrams.
4. valid_palindrome
   - Check whether a string reads the same forward and backward after stripping non-alphanumeric characters.
5. best_time_to_buy_and_sell_stock
   - Find the maximum single trade profit from a price list.

## What to practice
- Hash map and set usage
- Two-pointer reasoning
- Cleaning input before comparison
- One-pass optimisation patterns
