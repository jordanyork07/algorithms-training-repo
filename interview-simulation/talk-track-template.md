# Talk-Track Template

1. Restate the problem in your own words.
2. Clarify the input and output contract.
3. Ask about constraints and edge cases.
4. Describe a brute-force approach.
5. Identify the bottleneck.
6. Explain the improved approach.
7. State the complexity before coding.
8. Implement and narrate key decisions.
9. Run through examples and edge cases.
10. Summarize the final algorithm and trade-offs.
