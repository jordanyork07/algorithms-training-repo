# Trees and Graphs

This topic focuses on connectivity, traversal, and recursion over hierarchical or networked data. The key challenge is usually deciding whether to search depth-first, breadth-first, or recursively through structure.

## Problems in this folder
1. max_depth_binary_tree
   - Compute the maximum depth of a binary tree.
   - Typical interview cues: recursive decomposition, base case handling, tree height.
2. number_of_islands
   - Count connected components of land cells in a grid.
   - Typical interview cues: DFS/BFS, visited sets, boundary checks.

## What to practice
- Tree recursion and base cases
- Graph traversal with a visited set
- Using the problem structure instead of brute force over all node pairs
