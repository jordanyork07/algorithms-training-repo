# Practice workflow

The practice files in each topic folder intentionally raise NotImplementedError until you implement them.

Use the `reference_tests/` directory to validate known-good solutions and keep the practice loop realistic.

## 40-minute interview simulation

Use this format when you want to rehearse the exact live-coding pressure.

### 0-5 minutes: understand and clarify
- Restate the problem in your own words
- Call out the input and output contract
- Ask about edge cases or ambiguous behavior
- Identify whether the prompt is asking for a simple pattern or a more complex combination of ideas

### 5-15 minutes: reason
- Explain the brute-force solution
- Find the bottleneck
- Decide which pattern is relevant: hash map, two pointers, binary search, BFS/DFS, DP, greedy, backtracking, etc.
- State the intended complexity before coding

### 15-30 minutes: implement
- Write code in a clean, structured way
- Keep variable names understandable
- Use helper functions if the logic benefits from clarity
- Narrate the main decisions out loud

### 30-35 minutes: validate
- Run through the provided examples
- Test one or two edge cases
- Check for off-by-one and boundary issues
- If the solution is incomplete, explain what remains and why

### 35-40 minutes: summarise
- Walk through the algorithm in plain English
- Explain the time and space complexity
- Say what you would improve next if you had more time

## Rules to mirror the real interview
- No AI tools
- No secret access to a prewritten solution
- Speak your reasoning out loud
- Don’t hide the fact that you are exploring the problem
- Focus on clarity and structure over cleverness
- If you hit a dead end, say what you are checking and move to the next valid idea

## Study loop
1. Attempt a problem without reading the reference solution
2. Write down the pattern you think applies
3. Check the reference solution only after you have a working draft or a clear explanation
4. Re-solve the problem from a blank file the next day
5. Record what you struggled with and repeat the weak patterns
